# Makhana Website 🌿

This repository contains the codebase for a modern and responsive website focused on **Makhana (fox nuts)** – a healthy superfood native to India. The site highlights its health benefits, usage in recipes, and offers an e-commerce section for online purchase.

## Features

- 🧾 Informative sections about Makhana (origin, benefits, uses)
- 📸 Recipe gallery and blogs
- 🛒 E-commerce section to buy Makhana online
- 📱 Fully responsive design for all devices
- 🔎 SEO-optimized layout and metadata
- 💬 Contact form and newsletter subscription

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Node.js / PHP (optional)
- Database: MongoDB / MySQL (if dynamic)
- Hosting: GitHub Pages / Vercel / Netlify
